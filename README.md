## 🧠 Overview

SKlauncher 4.0 is a refreshed Minecraft: Java Edition launcher focused on convenient instance management and flexible configuration. It gives players a central place to organize different Minecraft versions, mods, modpacks, profiles, and game settings while keeping each setup separated from the others.

The launcher combines support for vanilla and modified installations with tools for managing Java, accounts, instance files, and additional content. Its redesigned interface is intended to make switching between different Minecraft environments more straightforward, whether you are playing an older release, a current version, or experimenting with snapshots.

## Additional Information for Windows Users

SKlauncher 4.0 uses separate instances to keep different Minecraft configurations independent. This approach is useful when maintaining several versions of the game, as each profile can contain its own mods, worlds, settings, and additional files without interfering with other installations.

Java configuration is handled within the launcher, helping simplify the setup process for Minecraft versions that require different runtime environments. Integrated mod and modpack functionality can also reduce the amount of manual file management involved when creating customized installations.

As version 4.0 is distributed as an open beta, certain features and interface elements may still evolve during development. Windows security warnings can also appear for beta builds that do not have a traditional code-signing certificate.
